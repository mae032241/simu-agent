# R5-E5.5 图像曲线提取最小复用设计

状态：完成；源码、真实 Fig.4 回归和安装态子智能体可视化自检均通过  
范围：只调整 `curve_figure_evidence` 插件内的图像曲线提取链  
目标：恢复已经跑通过的“智能体标定、程序取点”能力，并让同一智能体通过重绘结果自校验

## 1. 不再做什么

- 不自动识别图框、坐标轴、刻度字符和曲线科学身份；
- 不使用 OCR 或 Tesseract；
- 不新增 Operation、角色、审查智能体、注册表、状态机或审批；
- 不重写来源恢复、坐标换算、CSV、证据清单或绘图框架；
- 不修改控制面、调度器、Intake、TCAD 或其他插件；
- 不让智能体填写点数、曲线数值范围、最大缺口、覆盖率或共享区间；
- 不把 `min_points`、可见率、最大间隙或端点种子等经验值作为结果准入条件。

## 2. 唯一运行链

```text
paper_source + research_objective
  -> science.figure.request.prepare.v1（保留原 Operation）
       -> 查看 PDF 文本和原始图像
       -> 智能体填写图像解释与标定信息
       -> 调用确定性预览工具
            -> 像素提取
            -> 数值还原
            -> 原图叠加图
            -> 数值重绘图
       -> 智能体查看两张图；不满意则修改请求并再次调用
       -> 智能体提交已自校验的 figure_request
  -> science.figure.evidence.materialize.v1（保留原 Operation）
       -> 使用同一源码和同一请求确定性重放
       -> 输出曲线 CSV、两张图、manifest 和报告
```

曲线提取不再启动独立科学审查智能体。现存的通用证据审计能力不在本次改动
范围内，但不作为上述提取闭环的步骤或通过条件。

## 3. 智能体与代码的边界

智能体只提交以下可从原图判断的信息：

- PDF 页和嵌入图身份；
- 图号、面板、数据图框；
- 每根轴的线性／对数类型、单位和至少两个可见刻度的
  `（像素坐标，刻度值）`；
- 每条曲线的名称、科学身份、颜色、线型、图例或标注区域；
- 用于区分同色曲线的少量曲线上引导点；
- 图例、文字和插图等明确不属于数据曲线的排除框。

确定性代码负责其余全部内容：

- 从绑定的真实源图读取多颜色曲线像素；
- 对刻度对排序并完成线性或 `log10` 数值换算；
- 自动计算点序、点数、像素范围、数值范围、缺列和覆盖率；
- 根据各系列实际选中的像素簇计算共享像素；
- 共享像素分别出现在相关曲线中，同时带同一个共享标识；
- 生成 CSV、manifest、报告、原图叠加图和数值重绘图。

程序只能共享真实被多个系列选中的可见像素，不凭另一条曲线补造完全不可见的
曲线段。是否跟错线由智能体查看重绘结果后修正标定、引导点或排除框。

## 4. 直接复用的源码

| 已有源码 | 处理方式 |
| --- | --- |
| `figure_source.py` | 原样复用 PDF 嵌入图和栅格图恢复、摘要、页和对象身份 |
| `FigureDigitizationRequest` | 沿用一个请求对象；裁掉自动检测候选和结果统计输入 |
| `calibration_from_tick_pairs`、`axis_value`、`axis_uncertainty` | 原样复用刻度归一化、线性／对数换算和误差传播 |
| `figure_line_tracker.py` | 首版继续复用已经用于 Fig.4 的颜色取点和路径跟踪；只取消经验阈值造成的拒绝，不另写跟踪器 |
| `build_digitized_figure_bundle` | 作为预览工具和正式 materialize 的唯一实现，不复制算法 |
| `_curve_csv`、`_audit_overlay` | 原样复用 CSV 和原图像素叠加图 |
| 8765 的 `render_curve_support.py` | 只迁入其现成的“从 CSV 按线性／对数轴重绘”函数，不重新设计绘图器 |
| 现有 OperationSpec／插件入口 | 原样复用，只改变端口接线和工具清单 |

旧 InGaAs `figure_geometry.json` 只作为真实 Fig.4 回归输入，不能重新注册为领域
编译器，也不能进入生产运行时。

## 5. 仅需修改的接线

1. `figure_worker_tool.py`
   - inspection 只返回原始页图和嵌入图，不运行 OCR 和自动检测；
   - 增加一个很薄的预览工具适配器：接收草稿 `figure_request`，直接调用
     `build_digitized_figure_bundle`，把原图叠加图和数值重绘图放入当前 Worker
     工作区供原生看图工具读取。

2. `figure_science_operations.py`
   - `science.figure.request.prepare.v1` 直接输出 `figure_request`；
   - 给该 Operation 注册原始图检查工具和确定性预览工具；
   - 提示词要求智能体在提交前实际查看两张预览图；
   - 不再输出 `figure_intent`，不再要求候选编号、检测收据或 OCR 锚点。

3. `operation_transforms.py`
   - materialize 输入由 `paper_source + figure_intent` 改为
     `paper_source + figure_request`；
   - 直接调用现有 `build_digitized_figure_bundle`；
   - 不再生成第二份 `figure_request`。

4. `figure_digitization_contract.py` 与 `figure_digitization.py`
   - 刻度输入使用无顺序含义的刻度对，由程序归一化；
   - 点数、范围、覆盖率、缺口和共享支持只作为程序输出；
   - 现有跟踪诊断可以写入报告，但不能因固定阈值拒绝已经提取出的真实像素；
   - 共享标记由实际像素结果生成，不接受智能体填写 `shared_support`。

除上述四处接线及复用的数值重绘函数外，不改其他生产模块。

## 6. 实施顺序

1. 先用旧 Fig.4 标定夹具直接调用当前 `build_digitized_figure_bundle`，确认已有
   手工标定路径仍能输出曲线；失败时只记录真实断点，不先改算法。
2. 改 inspection 和请求 Operation，使智能体能提交完整请求并调用同一数字化器
   预览。
3. 改 materialize 接线，验证预览与正式物化逐字节一致。
4. 接入 8765 的数值重绘函数，并让智能体查看原图叠加图与数值重绘图。
5. 最后只删除已经没有生产引用的自动检测、OCR 接线和相应测试；不顺带清理
   其他代码。

## 7. 最小验收

- 同一个 Fig.4 请求可由智能体预览并正式物化；
- 预览和正式物化的 CSV、manifest、叠加图与重绘图一致；
- 红色和黑色曲线点来自绑定原图的真实像素；
- 线性／对数轴均由智能体给出的刻度对正确还原；
- 点数、范围、缺口和共享标识均由程序生成；
- 智能体实际查看两张图后才提交；
- 运行路径不调用 OCR、自动图框、自动识轴或独立图像审查智能体；
- 串行测试，峰值内存低于 8 GiB。

达到这些条件即完成；不在本轮追加泛化评测、UI 改造或新的科学治理能力。

## 8. 实施记录

截至 2026-09-06，源码已按本设计完成以下收敛：

- 请求智能体只接收原始来源检查和确定性预览两个图像工具，不再调用 OCR、自动图框或自动识轴；
- 预览与正式物化共用 `build_digitized_figure_bundle`，同时产生原图叠加图和数值重绘图；
- 点数、范围、缺列、覆盖率和共享像素均由程序从实际像素结果生成；
- 已删除无生产入口的自动检测实现、自动版清单分支及其旧测试；
- Pillow 与 `pdfimages` 是图像插件仅有的安装态依赖，Tesseract 不再参与安装或运行。

已通过的证据：

- 图像最小链、语义编译和可选插件测试共 19 项通过；
- 安装态插件契约、变换等价与图像依赖预检通过；
- 使用真实论文 PDF 第 6 页对象 241 和旧 Fig.4 标定信息回归：黑线 809 点、红线 802 点，
  红线局部最大缺列 3 像素但不拒绝，共 1611 行可定量，输出两张预览图；耗时约 3.7 秒、
  峰值内存约 72 MiB。

安装态验收于 2026-09-06 完成：

  `fig4_e55_minimal_visual_request_1` 完成，候选被控制面接受，封存信号为 `pass`，并记录已完成
  确定性预览核对；
- 封存请求选择 PDF 第 6 页嵌入图对象 241，使用线性深度轴、`log10` 浓度轴，并分别绑定

- 同一封存请求经 `science.figure.evidence.materialize.v1` 确定性重放成功，输出一张原始来源图、

- 本轮没有调用旧 Fig.4 案例插件、OCR、自动图框、自动识轴或独立图像审查智能体。

因此“同一智能体通过原图叠加图和数值重绘图完成可视化自检”已满足本设计的最小验收条件。
