## 2. 常数扩散方程的数学形式

对一个只通过扩散输运、无体源项的浓度状态，采用 Fick 通量并结合局部质量守恒：

\[
J=-D\frac{\partial C}{\partial x},\qquad
\frac{\partial C}{\partial t}=-\frac{\partial J}{\partial x}.
\]

当 D 为常数时，得到：

\[
\frac{\partial C}{\partial t}=D\frac{\partial^2 C}{\partial x^2}.
\]

这是标准的一维 Fick 扩散方程。“自定义”指在求解器中自行声明状态和方程，并非自行发明扩散规律。通量、守恒推导及适用条件见 [MIT 扩散讲义，第 7—9 个 PDF 页面](https://ocw.mit.edu/courses/3-091sc-introduction-to-solid-state-chemistry-fall-2010/e984fbef910102c34ac5ef86f1c939c8_MIT3_091SCF09_aln09.pdf)。

## 3. 边界条件与测量量尚需对应真实实验

既往基线指定：

\[
C(x,0)=0\quad(0<x<L),\qquad C(0,t)=C_s,\qquad C(L,t)=0.
\]

这些条件分别假设初始体内浓度为零、表面始终维持固定浓度、远端维持零浓度。配合常数 D，它们构成一个可检验的简化模型，但方程标准并不能证明这些假设符合论文实验。

必须核对方程中的 C 对应论文的哪一种测量量。总掺杂浓度、可迁移组分浓度和电活性浓度不能未经说明直接等同。若数据中的平台涉及背景浓度或测量限制，也不能在未核对之前将其直接解释成该状态的扩散尾部。

这里记录的是模型适用性待核验项，不是认定论文存在某一种未建模机制，也不是自动增加物理项的理由。

## 4. 为什么只调 D 和 Cs 可能不够

在半无限域、零初始浓度和恒定表面浓度条件下，解析解为：

\[
C(x,t)=C_s\,\operatorname{erfc}\!\left(\frac{x}{2\sqrt{Dt}}\right).
\]

该解见 [MIT 扩散讲义](https://ocw.mit.edu/courses/3-091sc-introduction-to-solid-state-chemistry-fall-2010/e984fbef910102c34ac5ef86f1c939c8_MIT3_091SCF09_aln09.pdf)。对于实际有限计算域，只有远端边界影响可忽略时才能用它作近似对照，不能直接当作有限域的严格解。

由此式可见，Cs 控制浓度幅度，√(Dt) 控制深度尺度；前部、过渡和尾部形状相互关联，没有独立调整所有形态特征的自由度。这说明需要检验模型族是否足够，而不只是继续改变两个参数。它本身并不证明 Fig4 一定无法由该模型拟合。

数值实现与适用条件匹配的解析解比较，可以用来区分求解实现误差与模型本身的局限。本文没有执行该比较，也不宣称既往数值解已通过这项核验。

## 5. 浓度相关扩散必须保留守恒通量形式

当扩散系数改为 D(C) 时，所讨论的 Fick 型模型应写为：

\[
\frac{\partial C}{\partial t}
=\frac{\partial}{\partial x}
\left[D(C)\frac{\partial C}{\partial x}\right].
\]

在 D(C) 可微时，展开为：

\[
\frac{\partial C}{\partial t}
=D(C)\frac{\partial^2 C}{\partial x^2}
+D'(C)\left(\frac{\partial C}{\partial x}\right)^2.
\]

因此，一般不能仅将常数方程中的 D 替换为 D(C) 并留在二阶导数外，否则会漏掉后一项。该展开是对守恒方程的数学说明，不表示最新源码已经出现这种错误。

仓库内的 [SProcess R-2020.09 实现参考](../skills/sentaurus-tcad-code/references/sprocess-r2020.09-recipes.md)说明，Alagator 中的梯度通量形式由求解器施加外层散度。因此，不能仅因表达式写作 `D(C)*grad(C)` 就认定少了散度；必须结合求解器语义核对。该参考指向相应版本手册 PDF 第 663—671 页，本文没有逐项复审最新实际源码。

## 6. 当前可表达的结论与核验顺序

1. 常数 D 方程的形式正确，可以作为基线。
2. 已执行实验主要检验有效扩散模型，不能等同于完整材料参数验证。
3. 基线失配只支持对已测模型和条件的有限结论，不能直接否定真实材料的所有扩散机制。
4. 新 D(C) 模型需要分别验证数学形式、求解实现和实验适用性；收敛成功本身也不证明物理正确。

讨论中提出的核验顺序是：先核对有效方程及单位，并用匹配条件的解析解检查基线数值实现；再核对测量量、初始条件、表面供给和参数来源；最后判断是否有依据改变模型。此顺序仅保存讨论建议，不授权启动新任务或变更已审实验。
