## 1. 研究目标与结论边界

研究对象是 supplied paper Fig4 的 InGaAs、InAlAs 浓度—深度曲线，已讨论的实验采用论文对应的 480°C、480 秒条件。

用户明确的完成标准是：得到有证据支持的良好仿真实测对齐，或者在实际检验范围内说明为什么不能对齐、已经排除什么、还缺什么。不能用没有解释的 inconclusive 或未完成执行冒充科学闭环。

目标后来明确聚焦于：

- 掺杂深度；
- 曲线整体形状与过渡区；
- 前部和尾部平台；
- 与上述判断相匹配的数值对照和参考数据不确定性。

对数浓度误差是辅助信息，单一 decade 阈值不能代替这些目标。历史记录中的 0.15 decade 阈值属于旧计划的判断条件，不是普适物理标准，也不能自动沿用为新目标的门槛。

### 2.1 基线形貌分析确实得到的结果

[封存形貌分析](plans/evidence/scheduler-attempt-budget/LIVE_FIG4.zh-CN.md)记录的中央 M0 估计为：

| 指标 | InGaAs：参考 → 仿真 | InAlAs：参考 → 仿真 |
| --- | --- | --- |
| 操作性深度终点 b2，μm | 0.387624 → 0.535149 | 0.474752 → 0.618317 |
| 过渡宽度，μm | 0.053465 → 0.262376 | 0.054455 → 0.176238 |
| 尾段中心 log10(cm⁻³) | 15.933217 → 18.473775 | 15.670704 → 18.712136 |

这些是指定模型、有效范围和分段方法下的描述性中央结果。48 个数字化角点中，38 个破坏块内严格 x 次序，10 个产生非正或非有限浓度；所以不能把中央差异直接升级成完整不确定度支持的复现否定。

[详细曲线诊断的真实验证](plans/evidence/analysis-closeout/LIVE_VERIFICATION.zh-CN.md)确认分析者实际调用工具并查看图像。探索性残差在参考曲线陡降后增大并延续到尾段，与上述偏差方向一致。工具的残差分段边界不是已验证的梯度变点或物理界面，也不能替代正式数据范围和不确定度条件。

### 2.2 20 工况扫描确实得到的结果

[现场执行与分析记录](plans/evidence/operation-validation-ownership-cleanup/collection-implementation/POSTINSTALL_RESULT.zh-CN.md)确认 20 例完整。两材料代表均为 mid-D/high-Cs，位于 Cs 高边界。

| 指标 | InGaAs | InAlAs |
| --- | --- | --- |
| 前区水平误差，历史 → 本轮，decade | 0.127666 → 0.009095 | 0.181563 → 0.005931 |
| 参考 x1，μm | 约 0.350779 | 0.433058 |
| 本轮代表 x1，μm | 0.548899 | 0.716033 |
| x1 偏深量，μm | 0.198119 | 0.282975 |
| 验证区 RMS，历史 → 本轮，decade | 1.943902 → 1.713324 | 2.141178 → 1.838940 |

x1 是该计划定义的相对前水平下降一个数量级的交点，不能与前表采用分段拟合的 b2 混用。InGaAs 的参考 x3 不唯一，InAlAs 对应尾区缺少合格参考块，相关尾指标不可判定。

这一轮支持“前部幅度明显改善，但深度与整体形状未同时还原”的有限结论，不支持“常数 D/Cs 家族永远不可能拟合”。随后 [独立审查](plans/evidence/operation-validation-ownership-cleanup/collection-implementation/FIG4_PAUSE_ANOMALY_AUDIT_20260913.zh-CN.md)识别到新增 Cs 扫描信息价值不足，以及旧数值对照被套用到不匹配参数点的问题；这属于有意义的科学审查，不能与机械输出拒绝混为一谈。

### 2.3 非线性实现失败与下一方案

依据主线程此前已回读的封存记录，浓度相关扩散实现的失败链为：

1. `pow` 表达式不受支持；改写表达式后越过该问题。
2. `min/max` 截断遇到 `MinMaxExpr::Derivative not implemented`。
3. 改为平方根表达式后，初始化的首个非线性扩散步不收敛。
4. 独立实现审查要求仅启用阻尼再验证；阻尼开启后仍出现 `Convergence problem during PDE solve`，没有取得所需初始化产品。

中间另有控制层将旧 ImplementationGap 误解析为完整 DeckProjectDraft 的问题。该工程缺陷修复后，新的修订确实启动了求解器并诚实封存收敛失败，因而后一次失败不能继续归因于同一输入兼容错误。

正则化四案例方案改变了模型近似，需要新的设计及匹配审查，不能由 author 作为普通代码修复自行决定。本文没有把该方案的提出写成执行成功，也没有从初始化失败推导物理模型被否定。

## 3. 各角色实际如何交接

研究中的常见路径为：

```text
论文和图证 → 科学基础 → 假设提出及独立批评
                            ↓
总体目标 + 已有计划、结果、分析、缺口
                            ↓
本轮设计 → 独立科学审查 → author 实现与最小初始化
                            ↓
独立实现审查 → 精确人工审批 → 正式执行
                            ↓
状态/日志同步 → 产物收集 → 结果分析与按需曲线工具
                            ↓
有限科学结论 → 选择下一轮设计、假设或证据动作
```

这只是已经使用过的路径说明，不是新增固定状态机。具体行动由主调度者从编译 Operation 目录选择，按声明绑定输入并预检。

- 控制层保存不可变输入绑定、Run 状态、成果版本、审批和恢复记录。
- 设计者选择本轮可执行目标，保留相关后续目标及其条件。
- author 实现计划；无法完成时交付具体缺口、源码和诊断，而非占位工程。
- 科学审查判断设计是否有依据、有信息价值；实现审查判断代码是否符合计划。
- 分析者按需调用评分、详细残差诊断和识图能力，证据不足时可以给有限结论。
- 主 Agent 阅读封存成果和交接信号，判断下一步；子 Agent 的聊天和未封存草稿不是正式科学结论。

代码错误但任务仍可行时进入受控实现修订；需要改变方程、方法或范围时返回设计；有效结果不能支持当前假设时形成有限结论并重新选择研究动作。框架、传输和提交故障单独记录，不能冒充科学反证。

## 7. 主 Agent 的 token 开销判断

这部分是根据接口和材料体积作出的结构判断，不是模型实际用量报告。当前源码检索未发现主 Agent 的 input_tokens/output_tokens 等用量汇总，不能给出总 token、缓存命中或实际费用。

主要开销来源：

1. [run_status](../src/scidiscovery/artifact_agent/interfaces/mcp_root_run_routes.py) 对已完成 Run 默认返回完整 sealed_output 及 scheduler_signal。主 Agent 并非默认只收到简短结论；重复读取同一完成状态可能重复携带正文。
2. 从计划恢复原目标、匹配审查及历史输入，需要查询父链和绑定。目录、元数据和请求在长期调度中也会反复出现。
3. 每次失败、修订、复审和部署都增加结果读取及重新调度；工程排错与科学讨论共同累积在父会话。
4. 最近紧凑入口主要减轻子 Agent 接手负担，不能直接认为父会话已同等缩小。

已有减负是子 Agent 不继承整段父会话、原件按需读取、报告缩短、错误历史分页及计算复用。调用编排还可以先筛选工具结果再展示，但接口返回字节不等于最终进入模型的 token。

本侧只读测量 [简版分析完成状态](plans/evidence/analysis-handoff-report-simplification/LIVE_COMPLETED_STATUS.json)：文件 20,020 字节，去展示缩进的 JSON 为 16,250 字节；其中正式报告为现场记录所列 9,171 字节。参考输入总量和本地命令 stdout 总量也不能当作模型实际阅读量。

讨论建议是：主 Agent 默认获得足以调度的结论、限制、缺口和精确引用，完整正文按需读取，并补真实用量观测。它尚不是已实施功能或获批变更计划，不取消现有科学审查，也不改变当前要求读取封存正文的规则。

## 8. 本回顾明确区分的三类问题

| 类别 | 本轮实例 | 应如何理解 |
| --- | --- | --- |
| 科学局限或有效审查 | 常数模型深度偏差、尾区不可判定、Cs 扩展无新增信息、数值对照适用对象不匹配 | 形成有范围的结论、补证据或调整实验；不能靠取消校验解决 |
| 数值/实现问题 | 表达式不支持、截断导数不支持、首次非线性步不收敛 | 按实际源码和日志判断；未获得有效结果前不能否定物理机制 |
| 框架与交付问题 | 输入重验、重复登记、名称/收集失败、诊断丢失、超时工作未保全、接手材料过重 | 修复控制与交接职责；保留原失败历史，不将修复成功等同科学目标完成 |

当前记录支持的有限判断是：参数调整已能改善前部浓度，但尚未同时还原深度、过渡和尾部；改变曲线形状的新模型仍在实现验证阶段。后续应依据新的封存结果更新研究判断，不能以本文代替实时控制记录。
