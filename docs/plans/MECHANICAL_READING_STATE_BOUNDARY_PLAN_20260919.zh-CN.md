## 1. 第一准则与证据

**Agent 选择研究材料、相关内容及是否继续阅读；控制层负责既有不可变输入绑定与工作区初始化，工具负责按绑定定位、本次分页期间的内容一致性、分页位置与重发。不得让 Agent 传递、保存或核对路径、哈希、版本和字节/字符偏移来维持一致性。**

科学引用别名、字段选择、真正需要操作的源码/数据文件名仍然可用；它们不是内部身份。只删读取包装中的机械字段，不扫描或改写科学原文中恰好名为 hash/path/version 的字段。

实测 B1 的 52 段 helper 回复包含 60,730 字节正文、17,864 字节元数据、3,365 字节外层字符串转义；首轮净增长反增 10.67%。复用轮净增长下降 55.14%，但不能把全部差额归功于哈希。下一轮应保留有效复用，删除把机械协议交给模型维护的部分。

## 4. R1：正文展示与内部读取记录分离

主修改：`service/input_reader.py`。继续由现有 `local_workspace.py` 安装，不另造读取框架。

1. 默认输出选中的精确正文，不再输出 source/sha256/version/offset/next_offset/total_characters 等包装；取消把正文再次包进 fragment JSON 字符串的外层转义。JSON 值自身必要的语法与转义保留，数字词形不变；全文模式仍能取得精确原始文本。
2. 必要时只有短的语义标题和“未完/已完”标识。单一已知选择不重复回显请求；多字段只标明对应字段，不能把不同字段拼成一个貌似完整的 JSON 对象。片段不能伪装成完整原件。
3. 正常 Agent 入口按 assignment 已有 source_name/port 选择绑定材料，再选 JSON Pointer/字段；脚本自行解析 relative_path，不复制一份绑定清单。一个端口有多个材料时使用现有可见科学别名明确选择，不暗选第一个。
4. 诊断日志、源码等工作区文件保留显式任务内相对文件选择；这是需要操作的业务对象，不回显内部绝对路径。不放宽现有工作区路径/符号链接边界，不用该工具读二进制 solver 产品。
5. 支持同一材料一次选取数个明确字段，复用现有 select/encode 逻辑。预算约束整个回复，不给每个字段各发一份完整预算；不新增跨材料通用批处理服务，也不自动目录展开、预读所有字段。
6. 保持默认 4 KiB、最大 8 KiB 的总显示预算作为最初对照条件。机械导航文字目标每次不超过 256 字节，不携带指纹或控制身份；长定位仍在内部记录。不可通过删科学正文、模糊错误或调大输出上限制造收益。
7. 完整机器记录供程序/人工调试按需取得；不把它列为 Agent 正常阅读步骤。保留 Python 级精确读取/定位能力供内部实现和已有工程调用，默认模型路径不再使用 offset/version 参数。

## 5. R2：续读由工具管理

交互仅需表达：开始读取一个明确选择、继续该选择、重发最近一段、从头重读。例如 `read_input.py experiment_plan --pointer /proposals --next`；不需要 Agent 填游标、版本或哈希。

- 为每个 Workspace 保留一份**可丢弃的工具私有导航缓存**，按材料及有序字段选择区分。只保存选择、本次读取内容的内部指纹、当前段起止和下一位置；不复制正文、不建已读履历、不登记 Agent 理解状态。
- 文件位于 Workspace 的工具私有位置，避开现有 output/scratch 恢复扫描范围；不进入 Artifact、checkpoint、恢复证据或新 Run，不加入日常 run_status。Workspace 清理时一起删除。全实例归档/删除规则不新增例外。
- 在已纳入范围的 `platforms/codex.py` 生成指引中明确狭窄例外：仅框架安装的 reader 可在上述固定私有位置自行维护导航缓存。Agent 及其他 helper 的临时文件和缓存仍遵守现有 scratch 规则；不要求 Agent 创建、编辑或复制该导航文件。不改变原生沙箱、科学文件写权限或执行授权，不新增权限实体。安装验收必须同时检查生成指引与 reader 实际行为，避免两套位置要求冲突。
- 起始读和显式 `--next` 只推进导航缓存，不修改 Run/Artifact/current。`--repeat` 重发最近一段且不推进；`--restart` 从头重读。不同材料/字段交错时不串页，串行锁与原子替换保护同一缓存，不增加任务锁或调度状态。
- 首次读取以当次内容建立导航基线，续读内部比较选择和内容指纹；发现相对该基线的源变更时不拼接旧、新版本，简短说明“材料已变化，请从头读取”。缓存缺失/损坏或新 Run 接续时也不猜偏移；允许从头重读，不拒绝科研提交。
- 保证范围仅为本次分页期间的一致性：现有 assignment 没有提供封存原件的预期内容哈希，reader 不声称能识别首次读取前的改动，或文件与缓存同时重建后的差异。既有不可变输入绑定与工作区初始化继续由控制层负责；导航指纹不是原件权威身份、安全凭据或提交资格依据。本轮不增加预期哈希清单、科学字段或新提交门禁；若需首次读取的独立封存字节核验，应另行明确需求与接口。
- 原子缓存不是交付确认：native 回复丢失或显示截断时，工具无法证明模型已收到。此时使用“重发最近一段”，不能把重新发一次 `--next` 当幂等重试；没有收悉信号就不承诺恰好一次交付。需要更早内容时从明确字段重新读取，不让 Agent 手工修游标。
- 这是为隐藏分页协议所需的最小短暂状态，明确取代前一 S1 的“完全无状态、Agent 回传版本/偏移”设计；不是第二套科研状态机或权限依据。Local 原生权限不变，不把可写缓存提升为安全凭据。
