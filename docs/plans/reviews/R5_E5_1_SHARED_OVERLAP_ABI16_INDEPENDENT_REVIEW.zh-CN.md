# R5 E5.1 重合共享 ABI 16 独立复审

日期：2026-09-05  
结论：**通过，阻断项 0**

## 审查边界

本次只审查论文图曲线的共享支撑扩展是否：

- 保持 Operation ABI 16 以及请求 v2、清单 v1、验证报告 v1；
- 继续读取既有严格 `overdraw`，并以可选分支加入 `coincident_overlap`；
- 只使用原图中真实直接像素，不插值、不平均、不重复授予定量资格；
- 不向核心控制面增加状态、注册表、资格实体或调度特例。

本审查不把合成测试等同于真实 Fig.4 科学验收，也不放行后续完整科学闭环。

## 独立对抗审查发现及修复

1. 校验器中断后只接入了一半的新数据结构，导致普通非共享路径报错。解析结果、调用签名和共享记录结构已统一。
2. 仅修改 CSV 来源名称并重算摘要可伪造共享来源。验证器现把声明来源绑定到原图像素颜色和容差。
3. 删除重合区或严格遮挡区两侧锚点并重算摘要可绕过。验证器现复核两种模式的直接锚点和距离约束。
4. 原始像素坐标可被移到同列远处的同色噪点，而亚像素坐标保持不变。标准表现要求原始坐标与亚像素轨迹一致。
5. 多成员同时可见时总选第一个成员，会让生成器随后拒绝自己的输出。物化器现确定性分配真实来源，使每个成员至少保留一个直接来源；无法分配时失败关闭。
6. `covered_eligible=true` 若直接拒绝会破坏旧 v2 请求解析。该字段继续作为兼容布尔字段读取，但复制行始终不具独立定量资格。
7. 插件运行依赖已更新到 `curve_score 0.2.1`，对应 Python 包依赖也同步，避免安装器解析到旧实现。
