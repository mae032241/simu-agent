## 2. 边界与最小改动原则

1. 科学 Agent 继续负责原科学判断；本修复不修改 Operation、Worker 输出 Schema、准入、输出校验、预算、Run 生命周期、批准条件或 VM runner。
2. 不增加 `epistemic_status`、`evidence_class` 等必填字段，不要求作者重复登记引用或补写一份 UI 报告。已有科学记录、引用与原 CSV 字节保持不变。
3. 展示层负责格式、关联已登记资料、中文固定标签及派生阅读缓存。译文不注册为科学 Artifact，不进入科学 inventory/current heads、独立审查或执行授权。
4. 读取历史材料不要求符合当前科学合同；不调用 preflight、当前资格检查或输出校验来决定能否画旧图、读旧参数。
5. 来源必须按已有确切引用、来源键及调用记录连接。不按名称相似、最近时间、文本匹配或同 Schema 自动补一条“看起来正确”的来源。
6. 不建通用知识图谱、翻译 Agent 工作流、多模型调度系统或通用 CSV 分析平台。曲线工作先复用已有数值重绘图，翻译只处理用户正在阅读的短文本片段。

## 4. P1：修正参数来源与参数表

### 4.1 按原记录类型展示，不倒推科学分类

| 原记录 | 页面主要说明 | 来源处理 |
| --- | --- | --- |
| 科学依据条目 / 器件参数声明 | 原记录已有的事实、推断、假设等分类 | 沿已有 evidence_keys、source_key、来源目录和 locator 展示 |
| 实验对照变量 / 案例设置 | 实验计划中的取值；显示已有物理、数值、实现类型及固定/变化角色 | 原计划、对应字段、案例取值和设计理由为直接来源；不因没有 epistemic_status 判为无来源 |
| 实现参数绑定 | 本实现采用的数值及代码定位 | 有明确 approved_parameter_key 时追溯确切已绑定参数集；已有 evidence_class/source 则原样解释 |
| 明确记录为工具默认值的项 | 工具默认及原记录说明的适用性/不确定性 | 只凭原记录明确声明标为默认，不能由字段缺失推断 |
| 未给出出处 / 页面无法解析 | 分别说明“该原记录未直接列出出处”或“展示暂未解析到引用” | 保留原件与确切缺口；不将解析异常改写成科研事实缺失 |

- 复用 `source`、`field_sources`、`rationale`、`factor_type`、`comparison_role` 等既有信息；必要新增字段仅限 UI 展示对象的可选说明，不传给 Worker。
- 修正 `general_science_views._proposals` 和 `presentation.parameter` 的默认行为；`_sources` 不再对所有空列表输出“来源未记录/是否默认未知”。
- 科学分类与文献引用分开显示。`paper_fact` 不等于页面已经成功定位论文，存在原计划链接也不等于数值已被实测证实。
- `acquisition` 依据已有 `source_type` 映射：冻结材料、网络快照、用户陈述、运行记录等。非网络材料不再一律显示“获得方式未记录”；未知类型保留原值及原件。
- 来源键匹配只在确切原记录的依赖范围内进行。多个历史来源目录出现相同 source_key 时，不跨目录拼接或自动选择最新版本；无法唯一定位就明确展示歧义。

### 4.2 精简而不隐藏关键参数

- 默认展示本轮取值，关联/历史取值单独展开；同名但来自不同版本或案例的值不静默合并。
- 固定类别、角色、单位名称和说明使用中文；数学符号、字段身份、变量路径保留可查。已有参数 display_name 优先使用；没有中文语义名时不能凭字典猜测物理含义。
- 每行显示名称、取值/单位、记录类型/依据、原件入口；案例细节与长理由按需展开。
- 移除“先把长行全部拼成 HTML，碰到 26 KiB 就只剩原件入口”的交付方式。复用当前节点的按需读取，提供明确的参数续页；计数区分总条数与本页条数。每次只读取/渲染选定的一页，不为表格展开整个祖先目录。
- 报告未提供不确定性估计时如实描述；不自动计算误差、推断默认值或替科学 Agent 判断可信度。

### 验收

## 5. P2：把原论文、CSV 和数值重绘接到证据节点

### 5.1 关联职责

- `read_model` 负责在当前实例和当前授权范围内读确切家族。使用已有调用指纹、绑定记录、父引用、输出端口、清单中的成员信息；不通过字符串后缀 `_001/_002` 猜曲线或图件身份。
- 必要时给 `scheduler_bindings` 增加一个按实例和既有 request_fingerprint 分页查询的只读方法，避免遍历整个实例。只增加查询，不改变登记、绑定、幂等或准入规则。
- 不直接调用 Root 的 `_transform_output_family` 来读取历史图证：该函数依赖当前编译目录和完整家族准入要求。展示只确认已保存的成员身份，并把缺失成员作为局部显示缺口。
- `curve_figure_evidence` 通过已有 `scidiscovery.instance_views` 入口增加纯展示提供者，解释本领域清单、轴信息、图例、CSV 和两类审计图；核心 UI 不复制图证科学合同。
- 本轮采用已有数值重绘 PNG；旧家族只有原图叠点而没有 numeric redraw 时，必须标明“原图叠点检查”，不能冒充独立 CSV 重绘。该历史家族保留 CSV 下载和缺口，不为补图重新跑提取或新增通用绘图引擎。

### 5.2 页面行为

- 原证据节点提供“论文曲线提取”区：原论文局部图、CSV 数值重绘、身份/取点叠图，标签区分三者。
- 同一面板显示曲线身份、轴单位、线性/对数尺度、CSV 记录的点数和对应下载入口；只展示已保存的标定，不猜比例、浓度单位或曲线名称。
- 曲线图默认进入证据区即可看到，不埋在来源 JSON 中；原 CSV 下载保持完整字节。参数与正文页面可链接到它实际引用的原证据节点，不自动切换为较新的版本。
- 审批页仍只读原请求 subjects 及原权限允许的资料；普通实例浏览凭据不能被混同为审批决定权限。未纳入审批读取范围的兄弟图件不能凭同实例身份穿透审批 token 的范围。
- 缺图、旧格式、插件未安装或歧义仅影响相应图卡；原件和其他页面仍可读，科研过程不因此失败。

### 验收

真实 Fig.4 原图与已保存 CSV 数值重绘能够并列看到；CSV 下载散列与注册原件一致。不同版本家族、相同名字、缺失一张图及旧合同均不导致错配或读旧资料触发科学准入。

## 6. P3：中文阅读副本（服务前提明确后实施）

### 6.1 内容范围

- 固定界面文案和已有枚举直接本地化；不调用模型翻译按钮、状态码、标识或机械字段。
- 科学正文选择该节点确切的正式摘要、任务目标、设计理由、限制和逐条结论进行忠实翻译。不是让模型重新分析实验，也不要求再生成一份研究报告。
- 英文原文及其原件入口保留。中文块明确标注“辅助译文”，保留原文版本、字段位置、生成时间与翻译配置版本。
- 页面有缓存时优先显示中文；没有缓存时提供“生成中文阅读稿”的明确按钮。原文始终能读，不把英文折叠本身当成中文化完成。

### 6.2 具体调用路径与职责

1. 用户在已授权页面发起 `POST /instance/<id>/reading-copy`；请求只包含服务器可解析的确切原件、JSON Pointer 和目标语言，不接收任意文件路径、URL 或用户替换的科学正文。
2. 服务复用现有 Host/Origin/CSRF 与实例 read scope 检查，再按原件身份读取授权文本。审批中的译文必须从原审批 token 的冻结读取范围解析，不能借此扩大范围。
3. 一个 UI 专用翻译适配器调用部署时选定的服务；没有工具执行、网络搜索、科研调度或文件写入权限。原文按数据处理，里面的指令不能改变翻译任务。
4. 先检查缓存；无缓存时限单个服务实例同时 1 个翻译请求，单次 30 秒，不自动重试。只发送选定的短文本：单片段不超过 8 KiB，每次合计不超过 32 KiB；原文超过时按段进入，明确指出剩余内容。服务响应上限 64 KiB，输出以转义文本显示，不执行模型返回 HTML/链接脚本。
5. 成功后写入实例 UI 缓存。失败只返回本块具体的连接、超时、鉴权或响应错误，保留后台 traceback；不包装成科学校验失败，不更新 Run 或审批状态。

这些限制控制 UI 翻译资源和权限，不是科学准入；达到限制仍可读原文与其他页面。网络等待不持有科研数据库事务或长时间维护锁；提交缓存前短时重查实例是否仍可写，若其间已归档则不写活动缓存。

### 6.3 缓存、归档与部署

- 在现有 `state/ui/workbench.sqlite3` 内增加一个 UI 阅读副本表，键包含 instance_id、原件身份/散列、JSON Pointer、目标语言和翻译配置版本。原件不同则不能复用译文；命中缓存之前仍执行原读取权限判断。
- 不把译文放进 Agent 工作目录、科研 CAS 或科学成果字段。译文不成为实例最新科研成果，不触发后续科学 Operation。
- 把译文表纳入现有缓存清理预览、清理、实例归档快照和恢复；清理不删原件。旧缓存或旧归档没有该表时按无译文处理，不能阻断历史资料读取或科研恢复。
- 已归档实例只展示已保存译文；新增译文写入须等实例恢复，避免修改归档。旧观察缓存兼容性处理限定在 UI 部分。
- 配置只由 `serve-approval-ui` 使用；未配置时清楚显示翻译不可用，科研服务照常运行。密钥留在服务端，不进页面、日志、仓库或 Run 输入。
- **部署服务地址、可用模型/翻译器、鉴权和协议样例尚待明确。** 不增加多提供者注册系统；若现有服务无法支持，先报告实际新增成本并修订 P3，不用 mock 通过代替真实中文验收。

### 验收

真实历史英文摘要能取得中文阅读副本，逐条核对数值、单位、否定、限定条件及结论强度没有改变。原文与来源可一键对照；重载复用缓存，清理后可重建，换原件不会错用旧译文。未配置、超时和返回异常时科研/审批读取行为保持。

## 8. P4：定向回归、独立审查和真实验收

### 工程回归

- 参数：有来源、来源歧义、对照变量、明确默认、真正缺失、旧合同、同名不同版本、续页和原件定位。
- 图证：完整家族、不同版本、兄弟产物缺失、原件下载、PNG 实际加载、插件移除和冻结审批范围负例。
- 中文：真实服务适配、忠实翻译人工对照、原件版本键、缓存权限、清理/归档/旧归档恢复、未配置及具体错误显示。mock 只用于确定性故障测试，不代替真实服务样本。
- 边界：原审批决定身份、实例绑定、研究接续、失败日志及既有缓存管理；50 项 Operation/工具声明与修改前一致，旧封存成果不被重写或重新验证。
- 打包：核心与现有插件的串行隔离 wheel 安装，新的展示提供者可发现；未启用翻译配置仍能启动原服务。

### 现场验收

在用户安装后仅对原 Fig.4 实例做浏览验收。使用确切来源的证据节点、参数表和历史英文摘要；记录截图及源字段定位。另在隔离状态中验证待审批表单，不能在真实实例试点“批准/拒绝”。

验收必须直接回答：

1. 进入原图证节点后，能否看见 CSV 对应的提取曲线及原论文对照？
2. 读参数行后，能否区分它的记录出处、科学依据类型和实际未明之处，而不是满表统一未知？
3. 能否用中文理解本次任务、结论、理由和主要限制，同时返回准确原文？
4. 旧科学材料仍可读，原审批和后续科研能力是否保持？

1280×900 与 390 宽度分别检查；实际展开图像和参数，不以懒加载前的 DOM 存在或 HTTP 200 充当可用性通过。默认节点页继续以不超过 2400 px 为目标；中文长正文按段进入，不为压低高度截掉限制条件。
