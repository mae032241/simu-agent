## 独审发现与修复

1. 未完成调用必须出现在观察范围中并标为 partial，不能被遗漏后显示 complete。
2. 子进程独立进程组；stdout、stderr 都限量；即使进程最终返回0，输送超限也不能变为已知成功。
3. 新投影复用原搜索解释校验，保留原执行用量/修复计数权威。
4. 父方案校验直接完成回执、模型摘要和任务身份；同节点父必须已先完成，复用关系不冒充派生。
5. 完成记录与原 stdout、row、terminal、本次模型交叉核对。候选ID、状态、run ID或跨调用模型替换均有拒绝负例。
6. v2 的完整性错误只在 v2 解释；v1 非法观察回复继续保留科学结果并记 unavailable。

领域适配器344行、通用谱系137行；另外只增加观察接线与抽取原校验。适配器超出最初单模块估量的部分是有界进程回包、精确原件绑定和可信配置入口；未增加第二套执行器、预算或调度状态。两份新增测试共365行，含独立CLI反例。

## 查询与入口边界

`cov_lineage configure` 由可信 launcher 在启动 Worker 前生成只读配置，读取冻结 job 与已接受 execution 身份。Worker 使用配置后的 `run --script … --parent-plan …` 或 `--new-plan`，不填写哈希与任务身份。原生 namespace 必须保留配置中既定的绝对路径及 runs 别名；当前门禁没有资格化新的 bwrap/native launcher。

查询仅读已持久化的 completed 原件。若 completed 缺失，即使 stdout、terminal 或模型文件存在，仍保守为 unknown，阻止该节点重发，不宣称已实现这一崩溃窗口的自动回收。旧普通 shell 来源不猜父；没有明确科学支持声明时 support 保持 unknown。

## 未覆盖的结论

不调用科研 LLM，不恢复 N5，不将隐藏分数输入科学角色。无模型安装入口和真实 public 命令成功，均不能证明原生模型权限隔离、真实搜索收益、跨命名空间任意路径映射或长时间运行能力。后续真实场需使用新冻结的 launcher/config；旧封存任务不就地改写。
