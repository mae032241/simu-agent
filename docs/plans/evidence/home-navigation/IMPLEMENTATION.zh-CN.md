## 已实现的行为

- 首页分为实例管理、创建与绑定、待审批三个入口；当前绑定另有直接进入按钮。旧科研会话管理 URL 继续有效。浏览器保存的是原有短期管理凭据，仍按原时刻到期；过期时首页保留已有实例浏览入口，不误称科研会话未绑定。
- 独立实例管理页按 30 个实例分页，显示存储状态、绑定关系、已记录的活动任务与最近任务状态，进入已有状态/轨迹工作台。没有浏览权限时只展示原有基本信息；未配置维护组件时不显示不可用的维护入口。
- 审批、实例、节点、日志、证据、资料维护、历史元数据及浏览器错误页共用首页导航；当前实例页面还提供当前实例入口。原件下载和机器 JSON 保留原响应。
- 创建/绑定从首页发起。当前已绑定实例不重复改写绑定；切换当前实例或接管其他会话时，展示影响并单独确认。确认后的 SQLite 事务再次比较绑定快照，过时确认不创建实例、不转移绑定。保持原有单实例单会话规则；不根据绑定推断 Agent 在线，不停止任务，不形成科学执行授权。
- 串行回归发现上一轮紧凑轨迹渲染遗漏了 `show_artifacts=false` 偏好；已恢复成果节点隐藏与可恢复提示，只影响显示，不删原记录。

改动涉及 8 个既有生产文件和 2 个 UI 新文件。控制服务仅增加可选绑定快照比较，旧调用者不传参数时维持原行为；无数据库迁移、Operation、Worker、科学合同或运行状态机变更。
