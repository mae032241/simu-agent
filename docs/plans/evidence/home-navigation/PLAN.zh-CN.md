# 首页、导航与绑定入口修订

2026-09-15。用户授权按已讨论原则修改，并要求首页独立实例管理入口。以前一轮可用性R2工作树为增量基线；不回滚原有改动。

1. 首页统一显示当前科研会话、创建/绑定入口、待审批事项，并提供独立实例管理入口。旧`/instances?capability=...`保留为首页别名；用HttpOnly/SameSite cookie携带原有短期管理授权，保持原到期时间，不另行授予权限。
2. 实例管理页列出存储状态、绑定关系和已授权实例的最近任务状态，直接进入原状态/轨迹页。浏览仅发放原实例scope凭据，不更改科研绑定。创建、绑定、接续表单只在首页发起。
3. 页面共用导航：返回首页、实例管理、当前实例。覆盖原审批、节点、日志、证据、资料维护和旧元数据页；下载/机器JSON仍保留原格式。
4. 当前已绑定实例只需浏览；切换当前绑定或接管他会话时显示原/新实例及已记录活动任务，单独确认。用既有SQLite事务比较确认时的绑定快照，拒绝过时确认。保留单实例单会话原规则及历史记录；不推断Agent存活，不停止/重启任务，不修改科学准入或运行状态。
5. 定向测试无授权/过期权限、浏览不换绑、当前绑定幂等、接续确认/过时快照、创建切换和原审批权限。浏览器验收首页→实例管理→状态轨迹→原件→首页及确认流程（隔离合成状态），截图核对中文和手机布局。

不新增科学Operation、Worker职责、会话心跳或研究状态机。测试与浏览器串行，512MiB进程树保护；不运行全量测试、真实审批、科研Run或部署。
