# 科研节点软预算修订

状态：源码与安装入口验收通过；独立审查见 [review](ROOTLESS_SOFT_NODE_REVIEW_20261012.md)。真实模型协作收尾尚未验证，本轮零模型调用。

## 原因与现行规则

T5 的 H001 因 420 秒节点硬上限被终止，尚未形成最终结论。按用户反馈，新 `prepare` / CLI 默认 `node_budget_mode=soft`，节点额度作为收尾目标，不再因局部超额中断已接受的科研工作。

- 同时关闭软模式下三个局部中止来源：全角色节点额度、旧 W 搜索额度、运行中触及交付预留；保留原身份、boot、冻结哈希与计量核验。
- 整场启用时间、已观测 token 上限、传输及资源保护仍可中止。token 观测有延迟，不保证请求在途零超额。
- 新节点准入继续校验目标额度及交付预留；不足则进入现有收口路径。预留不再通过杀掉运行中的节点保全，已接受节点可能消耗它；无法完成模型收口时如实导出未提交状态，不追加授权。
- 显式 `--node-budget-mode hard` 保留旧行为；旧冻结配置缺少该字段也按 hard 读取。旧 T5 场及原任务文件不迁移、不重跑。
- 仅对已资格、已知失败的原会话开放超软目标续接。原节点消费、尝试数与共享额度累加，剩余目标钳到零，不能负数抵扣预留。unknown 与原资格限制保持。

## 轻量提示

宿主写 `work/budget-status.json`（最多 4096 字节），启动提示要求在自然动作边界查看，接近目标时保留结果并返回科学结论。它仅为建议，不进入成果封存，也不作为计量或授权来源。删除、伪造文件不能解除控制层硬预算。

提示按 5 秒节流，收到用量回执可更新；显示观测下界/在途未知及更新时间。写入使用固定工作目录、nofollow 目录描述符、独占随机临时文件及原子替换；遇到不可写、链接或非普通目标时提示可缺失，预算守卫独立运行。

当前原生 exec 只接收初始 stdin，没有已接线的运行中强制通知/让出接口。本次不承诺角色一定读取提示或及时封存。
