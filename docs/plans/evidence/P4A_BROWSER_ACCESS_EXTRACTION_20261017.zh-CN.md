# P4a：复用实例浏览凭据原语

状态：实现完成，[独立静态复核通过](P4A_BROWSER_ACCESS_EXTRACTION_REVIEW_20261017.zh-CN.md)。不代表 P4 实例 UI 或浏览器流程已验收。

## 迁移原因与范围

旧 `approval_ui/__init__.py` 会导入 `app`，直接从该包导入 `access` 也会装载旧服务依赖。新薄入口不应为复用浏览凭据而引入旧会话、Root 或数据库服务。

- 将 `approval_ui/access.py` 的原实现整体移至 `scidiscovery/browser_access.py`；旧路径显式重导出七个公共定义。
- 保留实例作用域、read/maintenance 区分、UI 启动身份使旧凭据失效、有效期、恢复时间界限和 cookie 规则。浏览凭据仍不授予科学资格或执行许可。
- 不新增权限、配置、UI、状态库或协议版本，不修改旧调用方。新的 CLI UI 接线仍属后续 P4；P3c 可复用此模块。
- 不纳入归档：旧归档模块混有 SQL/旧运行服务依赖，另行迁移必要原语。

## 静态检查

将新文件与迁移前 Git 原件比较，完整 AST 相同；旧路径导出集合等于原模块七个公共函数/类。检索到的旧消费者为 app 与现有浏览访问相关测试，未见私有 `_AAD/_utc/_timestamp` 的跨模块消费者。未复制旧测试或新增固定答案测试。

没有导入执行模块，没有运行 pytest、安装、构建或 HTTP 服务。旧浏览器行为与新入口动态验证均未运行，资源隔离限制继续有效。
