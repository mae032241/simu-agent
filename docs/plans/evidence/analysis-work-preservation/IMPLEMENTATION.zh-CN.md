## 验证结果

所有测试、构建和安装 smoke 串行执行。测试进程地址空间上限 512 MiB、CPU 上限 120 秒；
进程树另有 512 MiB RSS 与 150 秒墙钟监控，BLAS/OMP 单线程，无 pytest-xdist 或全量 pytest。
实测最高进程树 RSS **281.88 MiB**，无预算终止或 OOM。命令、耗时、峰值及失败日志均在
[checks.jsonl](checks.jsonl)，不是只记录一个通过计数。

定向覆盖恢复/author、原生进程、发布/提交、描述投影、Root 查询、校验职责、目录编译、插件边界、
通用/TCAD 分析及现有生命周期。各组通过数存在重叠，不以累加重复执行制造进展。
扩展检查发现的旧失败均按原样保留并在修改前源码快照复现：

- Local 生命周期四项：旧异常文案、preflight 返回新增 diagnostics 的整字典断言，以及符号链接错误摘要过于泛化。
- Hardened 六项：既有运行入口/审查者可用性拒绝，主要表现为 operation_runtime_unavailable；本轮未扩展 Hardened 支持。

因此没有宣称全仓测试通过，或这十项旧失败已修复。独立记录它们不改变实际错误输入仍被拒绝的事实。
本轮曾产生的三个旧格式返回兼容失败已修正：只有新恢复记录确实携带保留信息时才增加该投影，
不为旧记录编造 original_retained=false。其余实施过程中的测试失败与修复均保留在检查日志。

[隔离安装证据](installed-smoke.json)来自最终生产源码构建的 core/curve/TCAD 三个 wheel，
逐文件核对全部 13 个改动生产模块。无源码路径回退的安装环境编译 45 个 Operation，实际 stdio
进程完成“打开—原生绘图故障—失败保全—新任务/新 stdio 进程读取草稿—只补图—发布及提交”。
启动脚本在 wheel 中且工作区副本字节一致；已有数值字节不变、数值执行计数 1。
这证明安装与协议通路，不等于真实 AI Agent 已按要求完成科学判断。

`git diff --check` 通过，现有架构约束注册表测试通过。技能提及的 architecture validator 和
science-control bench 脚本在本仓库已不存在，仅发现于另一个历史快照；没有执行其他仓库的脚本
冒充本版本验证。本轮用实际 Local stdio 恢复链与定向边界测试提供相关证据，未声称通过旧全套 bench。

## 保留限制与部署后工作

1. 未确认全部原生写入停止时，原目录持续保留并显示 pending；不自动垃圾清理。子集可读不代表完整保存，
   原始日志、超限文件或快照后产生的文件可能仍只在原目录。完整保存且停写确认的显式清理分支由工程夹具覆盖。

   真实脚本必须由部署后的受控分析 Worker 基于绑定记录发布新版本，Root 未改写生产科学脚本或结果。
4. 线上 `/opt` 安装及现有科研实例未变。本会话写权限仅覆盖仓库与 `/tmp`，生产安装需用户按原部署流程执行。
