## 1. 责任与适用范围

[新入口 N0–N5 计划](ROOTLESS_SEARCH_AND_LONG_RUN_PLAN.zh-CN.md)继续维护现有机制、历史、恢复和纠偏的实施及验收状态。
本文负责前置 N6 预算内交付及后续“统一方案谱系与自适应搜索”的 T0–T5 设计，细化并推进 N2/N3；不把已有候选索引或有界 W 阶段表述成已实现的自适应树搜索。
[旧 HWA 搜索计划](RELIABLE_HWA_SEARCH_IMPLEMENTATION_PLAN.zh-CN.md)保留旧链设计及历史预算，不作为本轮执行授权。
恢复、权限、预算、受限材料和执行提交等已有约束继续有效。本文不引入 LLM Root，不新建并行的历史账本。

目标：**历史是已经探索的方案谱系，搜索是决定接下来扩展哪些节点。**
同一份谱系支撑历史找回、实现复用和科学决策。控制层保存原件，角色默认只看有界投影。
树结构只提供搜索依据，不保证评估与目标一致，更不保证全局最优。

两条必须分别验证的改进主线：

1. **便宜的自适应搜索（T3）**：根据结果分叉、回退，减少整批固定配方和重复核查；先测量，再决定是否需要辅助者拆步。
2. **评估盲区下的选择能力（T4）**：A 区分有据结论、条件性结论和未知；自建压力测试排名更高，不足以认定新候选更适合目标条件。

N6 解决预算内交付，不替代以上两条，也不承诺分数上升。

## 2. 结构与职责

底层允许有向无环图，默认按主要派生关系显示为树。机制与候选分层；一次科学任务可以产生多个候选，一个候选可由后续任务继续扩展，任务次数不等于候选次数。

| 关系 | 含义 | 记录规则 |
| --- | --- | --- |
| 派生 | 从哪个方案修改得到 | 一个主要父候选；无父候选的新建方案显式记录 |
| 复用 | 使用了其他节点的实现或材料 | 记录确切对象，不复制祖先附件全集 |
| 证据支持 | 哪些结果支持某个科学判断 | 科学作者给出主张和引用意图，控制层解析来源；不自动继承父节点资格 |

未知的历史关系保留为 unknown，不凭最近时间、文件相似度或同名猜测。现有历史节点可以进入索引，但不得伪造其候选父子关系。

| 角色 | 职责与默认工作集 |
| --- | --- |
| H | 面向全局目标管理机制组合，读取覆盖、反例和未决问题，提出或修订机制；必要时请求 E |
| W | 在 H 授权机制内选择候选、改进、修复、复核；读取当前父候选与少量相关分支 |
| A | 判断行动对全局目标的贡献，检查评估盲区，决定续搜、转向、补实验或交付 |
| E | 根据 H 的具体问题获取并封存证据，返回 H；不设为每轮必经阶段 |
| 控制层 | 维护身份、绑定、快照、机械指标、预算、执行和恢复；不替角色决定科学优劣 |

H→W→A、H→A 及 A→H/W 的现有合法路由保留。换机制由 H/A 决定；W 的实现自由度不能变成自行更换科学命题。

## 3. 搜索与历史共用的读取规则

默认投递：全局目标与当前边界、活跃分支一句话状态、当前父候选及必要文件、关键失败边界、A 推荐与实际提交。
旧节点留在持久化谱系中，通过有界分页及原件入口读取，退出默认上下文不等于删除记录。

候选视图区分：

- 同一评估版本下的代理最高候选，并标明指标盲区；
- A 推荐的交付候选及理由；
- 实际提交候选及执行确认状态；
- 未充分探索的分支、有效负结果和工程失败。

不同评估版本不直接排名；改善代理分数不自动等于接近全局目标。完整机械概览覆盖自动采集范围，作者未选中的记录也可查；观测范围之外显式标明。

## 4. 实施节点

每个节点遵循：独立实施 → 最小可信验证 → 独立审查 → Git 节点。不得以基线同样失败替代问题处置。节点未通过时不标完成。

### N5 收尾：零模型全候选池诊断

- 保存 token_limit、H017 未封存、实际提交和累计成本，区分协议 8 的真实补正成功与整场收口失败。
- 对 N5 和 live02 的全部台账候选做隔离离线评分。先冻结台账、模型、公共数据及 verifier 哈希，检查两场条件；不改原始提交，不调用科研模型。
- 逐候选列出公开验证、隐藏 recovery、reward、审计资格、来源及失败。缺少审计不得伪造 leakage=false；可单列条件性预测 reward，但不计为已通过审计的正式候选。模型丢失、载入失败、超时、未知来源计入分母和缺失报告。
- 同时报告可评分池、已审计池的池内最优，以及实际提交、A推荐、验证最高相对池内最优的选择损失；明确损失的候选资格和评分口径。池内最优只作事后上界，不能实际选择后再宣称未经隐藏信息的成绩。
- 计算验证与隐藏分数的 Spearman 秩相关，使用并列秩，列样本数、缺失与分组结果；候选互相依赖，不能作为独立重复样本估计框架稳定性。
- 比较 N5/live02 的成本、可评分池质量和选择损失。条件不一致必须列明；这些数据可以辨别已采样池中的选择缺口，不能唯一归因于搜索、评估或角色分工，也不能推断未探索机制的价值。
- 隐藏分数只保存在评估者目录，不反馈原场角色，不按隐藏答案编写 cov 专用规则。

退出：两池覆盖及缺失明确、指标可复算、独立审查通过，并补 N5/live02 对比。现有三候选评分是前期证据，不替代全池完成。

### N6：预算内交付保障（先于 T0 实施）

目标：在额度耗尽前形成 A 的明确交付选择，并落实为可确认的提交；保留旧提交同样是合法选择。该节点独立于谱系改造。

- 对 H/W/A/E 全部科研节点设置可执行的单节点 token/启用时间上限，不仅限制 W。明确原生用量可见性、请求在途超量及终止宽限；硬阈值是宿主观测后的停止策略，不承诺恰好零超量。
- 同时预留 A 决策、执行适配器提交、结果确认所需的 token、启用时间和节点名额；允许范围内的补正也要计入。依据实测角色成本和在途结算迟滞冻结保守参数，不直接采用未经验证的“典型 A ×1.5”。
- 派发每个新科研节点前，检查其可消耗额度是否侵占收口预留；临近预留边界时切换为有界 A 交付任务，不继续派发新的探索 H/W/E。已接受工作保留现有执行与恢复语义，不能承诺无界在途任务一定留足预算。
- A 明确保留或替换候选，给出依据、未知和未完成目标。已有 A 推荐可作为输入，不自动当成最终交付决定。
- 通用执行适配器负责提交和确认，cov 为一个实现；无适配器时使用显式有界交付动作。预算之外的执行仍须符合原权限与授权。
- 提交按精确候选绑定，已确认操作不重复执行，未知外部提交先恢复核对，不盲目重试；新提交未确认前，不将旧的有效提交记录抹掉。
- 提供硬停止后的显式收口命令：核验原任务确已停止、执行状态可恢复，使用剩余的已授权收口预留，读取已封存结果；不把被终止的未封存输出当作合格结论，不重放未知工作。若总额度已耗尽，只能零模型导出现有提交及未完成状态，额外模型收口需用户显式扩额。该命令不解除科学资格和执行权限，不自动恢复探索。
- 重启不重置预留、用量或收口状态。预算修订须有操作员授权；不存在可交付候选、预算已不足或收口失败时如实报告，不伪造完成。
- 区分“预算截止交付”与“科学目标完成”。用户原始停止条件保持原义，截止可保存候选但不能宣称条件均满足。

退出：确定性用例覆盖各角色单节点硬上限、token/时间/步数边界、在途超量、硬停止后收口命令、总预算不足、A选择保留、替换失败、未知提交、恢复和无候选；安装入口验证通过。真实交付验证用单独冻结场次或后续 T5，不自动重开已评分 N5。模块/接口方案先独审，实施后独立复审并提交。

### T0：冻结数据责任、边界与验收口径

当前[逐函数责任与冻结夹具设计](ROOTLESS_T0_LINEAGE_DESIGN.zh-CN.md)已独审通过并提交 `c1dea80`；首版候选入口选定领域 CLI 窄wrapper，正常确切回执绑定，缺失保unknown不重发，不据此标产品通过。首版 T3 原生 W 优先，辅助者未资格禁用；T4 只用公开规则，不按隐藏池调参。

- 带上 N5/live02 全池诊断，结合上下文和步骤成本确定 T3/T4 的主线与实施规模；高选择损失优先评估和选择，低池质量不直接等于树结构缺失。评估盲区和搜索效率两项都保留验收，不能由少数分数取消。
- 对照现有机制表、候选台账、历史投影、实现选择和插件适配器，列出复用、替换与删除项，精确到模块及函数：
  - `search`：机制组合及其投影复用为谱系机制层，重复机制汇总由统一读取替换；准入和阶段限制继续保留。
  - `history`：候选概览、节点索引改为统一谱系投影；移除重复拼装，保留精确原件入口及分页。
  - `semantic`：保留部分应用、unresolved 和有限作者补正；不复制候选/机制账本，引用统一身份解析。
  - `correction`：保留 A 决策周期计数和暂停语义，复用统一事实入口，不把候选数量当成纠偏轮数。
  - `budget`：保留唯一预算账本及 N6 预留，谱系仅引用成本事实，不维护第二份余额。
  - T0 评审必须给出逐函数迁移表和删除证据；不为减少模块数合并不同职责。
- 定义任务、机制、候选、评估版本之间的映射和三种关系；每项机械事实只有一个权威来源。
- 明确通用接口与领域插件分工；cov 台账是一个适配实现，不进入核心搜索逻辑。

- 核验原生平台能否启动独立上下文辅助者、是否能观察其释放，并测量启动开销。不能可靠释放时禁用辅助者策略，保留 W 原生执行有界步骤，不能让平台特性成为搜索可用性的前提。

### T1：可恢复的方案谱系

- 在现有封存节点和候选观察上建立可重建的关系投影。
- 记录候选父节点、所属机制、实现入口、评估版本、指标、状态和成本。
- 科学作者选择父方案与改动意图；控制层通过受管理执行上下文绑定机械身份和台账，不新增必须手写的机械父 ID 字段。
- 沿用协议 8：缺失历史关系标 unknown；显式非法或歧义选择标 unresolved，相关关系更新不生效，科学文本和其他有效更新照常封存。依赖该选择的执行被阻止并有限退回作者，不静默猜测或沿用旧父节点。完整性、权限、schema 和未知执行等硬失败边界保持。
- 保留 A 推荐、实际提交及来源区分；候选失败和未完成状态仍可追溯。
- 外部 shell 未登记的实验不被伪装成完整观测；通过适配器扩展采集，不让 W 手写文件清单、哈希或祖先引用。

退出：A→H→W 后旧实现直接可用；重启及重复采集幂等；组合复用可表示；未知来源不误连；父候选资格不自动继承。

### T2：H/W/A/E 共用的紧凑谱系视图

- 按第 2、3 节提供角色相关投影，保留完整概览入口和原始记录。
- 以谱系投影替换重复历史和搜索摘要，不同时维护多份状态。
- 明确截断、分页和缺失字段；失败经验包括科学负结果，不只包含工程报错。
- A 的完整概览由控制层机械生成，不能只包含 W 选取的主张。

退出：增加历史节点不会让默认上下文线性增长；关键失败与遗漏分支可找回；跨角色得到的同一节点身份一致；不复制祖先附件。

### T3：W 的机制内自适应搜索（按测量选择实施规模）

先使用 T0 数据判定：若原生 W 已能低成本自适应选择，优先接入谱系、消除重复读取和预排配方约束；只有观察到长上下文或重复执行瓶颈时才引入辅助者短步。不得把一次辅助者派发当成一次必经搜索步骤。

H 声明机制命题、范围、最小判别实验、必要对照、允许调整的自由度和评估适用范围；必要的科学预承诺保留。整轮不默认固化为一批预排配方。

W 反复执行：

1. 读取当前子树摘要、父候选、A 的问题及必要原件。
2. 选择新建、改进、修复或复核，说明本步能够改变的判断。
3. 在小预算片内执行并评估，控制层记录候选和结果。
4. 根据结果选择下一步；出现越界需要、关键反例、阶段额度耗尽或连续有效尝试无收益时交回 A。

实现步骤可由 W 原生执行或使用已验证的新上下文有界辅助者；几个廉价实验可组成一步。辅助者只拿必要工作集，完成即释放；W 保存摘要，减少重复日志和代码驻留。以单位有效步骤成本决定策略，不强制多套调度。
预算仍属于原实例与阶段，不因分支或辅助者重置；辅助者不成为新的科研任务或正式独立审查。

退出：观察改变后续选择；能回退旧候选并分叉；固定批量和重复核查的变化有测量；调试不算新机制；使用辅助者时名额确实释放；未知外部提交不重放；W 不越过 H 范围。未证实成本下降时不宣称效率收益。

### T4：A 的跨分支选择与评估盲区处理

- A 在阶段预算边界或方向性证据出现时做科学决策，不要求每次廉价实验都新增 A 节点。
- 可继续当前分支、切换已授权分支、请求改进评估、返回 H、推荐提交或结题。
- H 管理机制组合，A 审查覆盖与贡献；控制层执行已批准的投入边界和探索承诺，不判定机制语义。
- A 必须区分有证据支持的结论、依赖特定条件的判断和未知。每个代理注明能观测什么、不能观测什么；自建压力测试排名更高，不足以认定候选更适合目标条件。
- 代理无法观察目标条件时，代理分数不能单独成为淘汰该机制的理由。对排名随扰动强度或类型反转，A 应保留不确定性，提出合法可行的区分试验或说明选择依据，不能任意赋予压力条件目标权重。
- 将选择规则写成可执行条款：每条规则列公开输入、适用条件、候选资格、评估版本、输出动作及未知时的处理。先冻结规则及版本，再运行候选池回测；不得读取隐藏分数作为规则输入，不得针对池内 reward 网格调阈值。已看过隐藏结果的池只能作开发性诊断，不能当作独立验证；最终科学效果需新冻结真实场次。无法机械检验的语义判断保留 A 负责，并单列审查准则。
- 用预先冻结的排名反转及缺少目标代表性夹具，核验 A 不把代理胜出认作目标达成；阴性结论与未知不得混为一谈。
- 搜索与最终选择的评估需要区分用途、可见性和访问次数；具体隔离由插件能力支持。无法隔离时显式披露，不能宣称防止选择过拟合。
- 保留用户的停止要求；分开统计 W 候选尝试、阶段和 A 科学决策周期，用户原题的实验次数规则不被重新解释。
- 保存当前交付候选与继续探索分开。A 给出选择，由有权限的执行适配器落实；缺少适配器时安排明确交付动作。候选推荐不能冒充提交完成。
- 复用已提前实现的 N6 交付与预算预留，不在 T4 再建第二套收口状态。

退出：候选推荐与实际提交差异可见；能够边保存候选边探索；预算中止有明确交付状态；A 对未探索关键方向给出处置；提交失败或不确定不被隐藏。

4. 断点恢复不重复实验，不丢失已推荐/已提交候选；真实恢复资格单独记录。
5. 最终交付与 A 的选择一致，或如实记录执行失败；后者意味着交付项不通过。
6. 概览可找到作者未挑选的失败尝试，必要原件仍可核验。
