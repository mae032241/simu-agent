## 1. 发布目标与文档归属

本文件拥有[总路线](SCIENTIFIC_CONTINUATION_AND_SIMPLIFICATION_PLAN.zh-CN.md) P0、P1 和 P4 基础精简的详细实施计划。
[B 版](AUTONOMOUS_RESEARCH_RELEASE_PLAN.zh-CN.md)负责自主推进，
[C 版](RESEARCH_DELIVERY_EXPERIENCE_RELEASE_PLAN.zh-CN.md)负责增强交付体验。
A 可以独立发布：现有交互研究不依赖后台 Root，也应更稳定、入口更简洁、问题更容易定位。

完成标准：

- 必要科学字段的合同、实际填写表单和校验一致；机械身份、绑定、预算字段不要求 Agent 填写。
- 精确输入、用途限制、阶段交付、附件封存、下游消费及 UI 读取贯穿同一对象身份。
- 系统故障有明确诊断；未知提交先查回，不能靠重新命名或重新执行解决。
- 收敛重复上下文、诊断与基础用量处理，为 B 提供可直接复用的能力。
- 退役 hardened 专属执行实现，保留共享协议、原生权限和历史证据读取。
- 精简有实际调用者证据，不用减少行数代替功能验收。

保留插件平台、Operation 编译器、catalog ABI、版本化 Schema、不可变证据和确切审查绑定。
不实施后台循环、全面合并数据库、安装器整体改写或 OS 强隔离；[SEC-002](../../SECURITY.md)保持独立未关闭事项。
