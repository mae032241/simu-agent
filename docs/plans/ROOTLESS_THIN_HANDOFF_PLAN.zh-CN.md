# CLI 实例控制与薄 HWA 交接

日期：2026-10-11。分支：dev。基线：ff95dfc。
状态：新 CLI 源码节点独立审查通过，31 项定向检查及安装假进程闭环通过；旧 daemon、旧 UI 尚未退役。

## 用户确定的责任边界

- CLI 是实例的真实控制入口，直接启动原生 H/W/A/证据线程；不用 LLM Root，也不经 MCP 调度 Agent。
- H 拥有机制提出/修订及证据需求；W 在 H 范围内实验；A 判断对全局目标的贡献并选择下一步。
- H→W/A/证据/等待；W→A；A→H/W/证据/等待/结题。证据任务返回请求者。
- MCP 保留功能插件。实例、目标、引用、封存、持久化、预算、恢复和 UI 后续统一由 CLI 控制层负责。
- UI/端口由 CLI 管理，浏览器是实例的视图，不需要会话绑定。每实例一个跨进程推进写锁；只读不占锁。

## 数据与交接

同一 CLI 实例内，封存节点是唯一路由记录，没有第二套 Todo、目标、预算状态机。
科学原文、控制封装和原生执行日志分开存；控制层自动填角色、父引用及哈希。
下一角色只接父科学 payload 和当前明确绑定材料，不接父控制 envelope，不继承祖先附件。
原始目标每次可见。历史节点链在实例保留；本版还没有完整的历史按需查询服务。
A 结题是科学建议，控制程序不把它升级为科学正确性或正式资格。

## 验收与限制

每个代码节点独立审查，通过最小可信回归后提交。先验收真实 CLI/子进程路径，原生模型以假进程替代；
再另行安排真实模型场，分别报告 token、缓存、耗时、闭环与科学结果。
使用显式 native launcher 参数。原生 Codex 直启为本地软隔离；隐私/隐藏评分边界需要已验证的外部 wrapper。
不把本地文件哈希称作恶意执行者隔离，不假装旧资格与远端执行审批已迁移。

预算是实例准备时显式冻结的有限上限；原生计量可能滞后，不保证精确计费硬上限。
暂停阻止下一节点，已接受工作可完成封存；强制中断/崩溃导致的未知启动不自动重放。
当前墙钟从首次启动算起，暂停也计时；长 loop 的启用时长计法不在本节点内宣称完成。

旧计划中继续扩展 Root、增加搜索机制的实施顺序由本文件取代；历史验收记录保留。
