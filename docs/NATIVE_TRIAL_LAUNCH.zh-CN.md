# 原生模型试验的当前入口

当前从[薄 CLI](ROOTLESS_CLI.zh-CN.md)的显式 `prepare` / `run` 和冻结 native launcher 开始，
为每场固定目标、公开输入、模型配置、实例目录及有限 token/时间/步数预算。
每次真实模型或 solver 试验须有独立范围和预算，不重用已结束场的额度。

只运行已有获准的启动器，保留其原生权限；涉及隐藏材料或外部副作用时须沿已验证的边界与执行 gate。
不要为试验复制私有认证、修改共享 Codex 配置、恢复旧 daemon 或自动放宽沙箱。
原生输出、计量、封存、科学结论与限制分别记录；合成会话测试不证明真实线程续接资格。
监督策略和串行入口见[测试说明](../tests/README.md)。采样止损不保证内核硬内存上限。

需要离线核对原生用量时，`scripts/native_usage_audit.py` 只读取显式指定的确切线程日志，
不得扫描或公开私有会话正文。缺测保持缺测；cached input 已包含在 input 中，不重复累加。
指定日志的离线汇总不代替实时预算，也不能证明所有参与线程均已覆盖。
