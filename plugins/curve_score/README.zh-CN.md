# 曲线科学插件

下列 Operation 名称属于可复用插件库声明，不提供应用调度器或 Run 服务；
集成边界见[Plugin API](../../docs/PLUGIN_RUNTIME_API.md)。

`science.result.diagnose.v1` 承担完整分析任务：读取精确观测、计算、绘图、必要数值诊断并交付科学报告。
计划和独立审查是可选上下文；评分和残差定位在负责人内部连续完成。
旧曲线契约设计/审查、评分/覆盖率/误差分析调度链退役，解析、评分、覆盖和绘图算法保留。

调用宿主负责在失败后保留任务工作区与原件；所提供的 checkpoint 工具可在同一原件重试时复用精确数值工作。
科学文件只含观测、结果与限制，控制侧保存精确来源及凭据。TCAD 分析复用工作区并使用自己的原始输出解析器。
可选 `curve_figure_evidence` 插件负责论文图像证据与确定性曲线束适配。
