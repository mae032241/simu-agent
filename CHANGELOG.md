# Changelog

## Unreleased

- Added CAS-guarded atomic JSON Pointer patching for task-bound worker JSON,
  parseable-output progress gating, compact curve/validation experiment intent
  materialization, leaf-only actionable validation diagnostics, and an early
  single executable curve-spec policy.

- Separated generic SciDiscovery orchestration from the TCAD and InGaAs domain
  plugins.
- Added identity-free root and worker MCP boundaries, ResearchInstance binding,
  local approvals, deterministic transforms, and execution lifecycle control.
- Restored the deployed 8765 runtime as a Codex-only development baseline.
- Added direct SProcess/SDevice project authoring, review, revision, comparison,
  packaging, runtime attestation, and bounded SSH transport.
- Added portable Linux/WSL deployment, bilingual documentation, a clean Git
  release builder, and hermetic CI.
- Added unit-safe metric evaluation and a shared claim-decision projection for
  validation reports and layered diagnoses.
- Replaced executable TCAD package v1 with reviewed-package v2 bound to an
  explicit solver capability digest; local and remote runners reject drift.
- Added typed case/execution DAGs, trusted realization materialization,
  content-addressed binary project inputs, and layered runtime parser gates.
- Added transactional install rollback, quoted systemd paths, private workspace
  defaults, and exact Python runtime-identity checks.
- Moved SProcess case bindings, units, locators, realization manifests,
  capability identity, raw-output contracts, and preflight qualification out
  of deck author/reviewer prose into a deterministic source-bound project
  materializer; packaging now re-materializes exact source and rejects legacy
  manual projects.
- Added deterministic adaptive curve-error localization with diagnostician-visible
  PNG plots. Exact-zero log support and repeated-x seams remain visible but are
  masked from inapplicable metrics; PLX source points and row order are preserved.
- Bound every scientific experiment plan to an exact research objective,
  hypothesis portfolio, and machine-derived eligibility receipt; case settings
  and comparison expectations now form one strict control table, typed closure
  requirements participate in objective coverage, and scientific TCAD packages
  require exact passing objective coverage.
- Added explicit instance-scoped current-objective and current-plan selections;
  historical qualified objects remain immutable but cannot silently participate
  in readiness, scoring, or packaging after a current lineage is selected.
- Replaced default hand-authored `ExperimentPortfolio` expansion with compact
  `ExperimentDesignIntent` plus deterministic case/control materialization.
  The complete strict plan remains the only selectable downstream plan; legacy
  full-plan output stays available through an explicit compatibility profile.
- Added a 420-second first-parseable-progress lease for compact experiment
  design tasks, calibrated after the initial 120/300-second live probes proved
  too short for 62 KiB of scientific context. Heartbeat-only or invalid-JSON
  attempts still fail early instead of consuming the full creative-task budget.
- Separated sharp-front operator selection from acceptance thresholds: external
  target fits may remain unthresholded when evidence supplies no defensible
  tolerance, while required numerical-qualification gates still require one.
  Experiment-plan validation, curve-score profile selection, complete-plan
  reports, and readiness coverage now preserve that distinction end to end,
  including plans whose deterministic-check set is exactly empty.
